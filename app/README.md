# MMCl Lost & Found Management System

## Overview
A mobile application developed using Android Studio that implements the REST architecture to manage lost and found items within MMCL.

## Technologies
- Kotlin
- Jetpack Compose
- Retrofit
- REST API
- PHP
- MySQL
- XAMPP

## Features
- User Login/Register
- Report Lost Item
- Report Found Item
- View Items
- Search Items
- Update Item Status

## Architecture
Android App
↓
REST API
↓
MySQL Database

## Requirements
- Android Studio
- Android SDK 26+
- XAMPP
- PHP 8+
- MySQL
